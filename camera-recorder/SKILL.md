# 📹 Camera Recorder Skill

录制 MacBook 摄像头视频的技能。通过 ffmpeg 调用前置摄像头录制指定时长的视频，并支持发送到聊天。

---

## 🎯 触发条件

当用户提到以下关键词时触发：

- "录视频" / "录制视频" / "拍视频"
- "用摄像头录" / "前置摄像头"
- "record video" / "camera record"
- "拍一段" / "录一段"

---

## 🛠️ 能力说明

| 能力 | 说明 |
|------|------|
| **摄像头录制** | 调用 MacBook 前置摄像头（FaceTime HD Camera） |
| **自定义时长** | 支持指定录制时长（默认 30 秒） |
| **自定义文件名** | 支持指定输出文件名 |
| **视频发送** | 录制完成后自动发送到聊天 |
| **权限检测** | 自动检测摄像头权限和 ffmpeg 安装状态 |

---

## 📋 使用方法

### 基础用法

```
帮我录个视频
用摄像头录 10 秒
拍一段视频发给我
```

### 带参数用法

```
录制 60 秒视频，保存为 my_video.mp4
用前置摄像头录 30 秒
录视频，文件名用 boss_test
```

---

## 🔧 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| **duration** | 整数 | 30 | 录制时长（秒） |
| **filename** | 字符串 | 自动生成 | 输出文件名 |
| **send_to_chat** | 布尔 | true | 是否发送到聊天 |

---

## 🎬 输出规格

| 规格 | 值 |
|------|-----|
| **分辨率** | 1280x720 (720p HD) |
| **帧率** | 30 fps |
| **编码** | H.264 (libx264) |
| **格式** | MP4 |
| **像素格式** | yuv420p |

## ⚠️ 注意事项

### 权限要求

首次使用需要授权摄像头权限：
```
系统设置 → 隐私与安全性 → 摄像头
→ 允许「终端」或「ffmpeg」访问摄像头
```

### 依赖安装

```bash
# 检查 ffmpeg 是否安装
ffmpeg -version

# 如未安装
brew install ffmpeg
```

### 文件存储

- 默认保存路径：`/Users/zhubby/.klaw/workspace/`
- 文件名格式：`boss_video_YYYYMMDD_HHMMSS.mp4`

---

## 🦀 错误处理

| 错误 | 处理方式 |
|------|---------|
| **ffmpeg 未安装** | 自动执行 `brew install ffmpeg` |
| **摄像头权限不足** | 提示用户到系统设置授权 |
| **摄像头被占用** | 提示用户关闭其他应用（如 Zoom、FaceTime） |
| **录制失败** | 返回错误信息，建议重试 |
